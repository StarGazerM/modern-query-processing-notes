# R.0.0: reading ordinary Rust

This one-package program accompanies Rust Conversation R.0.0. From the notes
repository root, run:

```console
cargo run --manifest-path examples/rust-00-reading-rust/Cargo.toml
```

The root `[workspace]` table, with no additional members, only keeps this package
independent from an enclosing checkout. It does not create another package.
